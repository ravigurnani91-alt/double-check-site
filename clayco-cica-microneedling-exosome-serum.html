ClayCo Cica Microneedling Exosome Serum — "Needle-Free" Verdict

Category: Skincare / Serums  •  Ingredient focus: Cica, Exosomes/Spicules, Peptides, Ceramides

The Claim

"Exosome-derived spicules" create micro-channels like microneedling, tricking skin into a repair response — plus Cica, ceramides, and peptides for collagen and barrier support.

What's Actually In It (Full 17-Ingredient List)

IngredientVerdictEvidence
Centella Asiatica (Cica) Leaf VERIFIED Genuinely well-studied — calms inflammation, strengthens barrier, decades of use.
Sodium Hyaluronate VERIFIED Proven humectant with strong water-holding capacity.
Copper Tripeptide-1 VERIFIED Real, researched peptide that supports collagen signaling.
Ceramide NP VERIFIED Core skin-barrier lipid with a strong evidence base.
Hydrolyzed Sponge (the "spicule"/exosome-mimicking ingredient) MIXED This is the actual mechanical "microneedle" ingredient — physically abrasive micro-particles, not exosomes in the biological sense. The "exosome" name here is largely marketing on top of a mechanical spicule/exfoliant technology.
Allantoin VERIFIED Established soothing agent.
Phenoxyethanol, Disodium EDTA VERIFIED Standard, well-tolerated preservative and stabilizer.

Case File Verdict

This is a genuinely well-formulated barrier + hydration serum — Cica, ceramides, and copper peptide are all backed by solid evidence. But "Exosome" in the name is doing a lot of marketing work: the actual mechanism is a physical spicule/sponge particle, not a biological exosome. If you're buying this for Cica/ceramide/peptide benefits, it delivers. If you're buying it because you think it contains lab-grade exosomes — it doesn't.
